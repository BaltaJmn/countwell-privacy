# countwell-privacy

Public web of **Countwell**, a pill counter for iPhone. Served at <https://countwell.baltajmn.dev/>
by GitHub Pages from `main`, behind Cloudflare (CNAME `countwell` to `baltajmn.github.io`, proxied).

| Path | What it is |
|---|---|
| `index.html` | What the app does, price, support contact. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy. The URL in the app's paywall and in the App Store |
| `legal.html` | Legal notice (LSSI art. 10), same owner details as the other apps' webs |
| `cw/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Countwell`.
